# 01. 데이터셋 직접 만들기

## 목표 구조

```
dataset/
├─ train/
│   ├─ Happy/
│   ├─ Sad/
│   └─ Normal/
├─ val/
│   ├─ Happy/ · Sad/ · Normal/
└─ test/
    └─ Happy/ · Sad/ · Normal/
```

## 조건

| 항목 | 기준 |
|---|---|
| 클래스 | Happy · Sad · Normal (폴더명이 train/val/test 에서 동일) |
| 수량 | **클래스별 통일** (예: 각 100장). 불균형이면 한쪽으로 치우친 모델 |
| 비율 | train 70~80% · val 10~15% · test 10~15% |
| 중복 | 같은 이미지가 두 폴더에 있으면 안 됨 (시험 문제 유출) |
| val 최소 | 클래스당 20~30장 이상 |
| 다양성 | 각도·조명·배경이 다른 사진 |

## 직접 해보기

- [ ] Chrome 웹 스토어에서 **Image Downloader** 확장 설치
- [ ] 표정별로 이미지 수집 (클래스당 목표 장수를 먼저 정하기)
- [ ] 깨진 파일·중복 파일 제거
- [ ] 위 구조대로 폴더를 **직접** 만들고 이미지 나누기
- [ ] 클래스별 개수를 세어 표로 적기 (`dir` 또는 탐색기)
