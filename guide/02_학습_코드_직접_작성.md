# 02. 학습 코드 직접 작성

`train.py` 를 **본인이 직접** 작성한다. 아래는 주석 뼈대뿐이다.

```python
# 1. 라이브러리 불러오기  →  from ultralytics import ???

# 2. 모델 로드 (분류 전용 pretrained: yolo11n-cls.pt)

# 3. 모델 학습  →  data / epochs / batch / imgsz
```

## 파라미터

| 파라미터 | 뜻 | 이번 조건 |
|---|---|---|
| `data` | 데이터셋 **폴더** 경로 (안의 train/val 자동 인식) | `dataset` |
| `epochs` | 전체 데이터 반복 횟수. ↑ 정확도·시간↑, 너무 많으면 과적합 | 자유 |
| `batch` | 한 번에 올리는 이미지 수. 메모리 허용 범위에서 ↑ 빠름 | 자유 |
| `imgsz` | 입력 한 변 크기. ↑ 정밀, 속도↓ | **256 고정** |

## 직접 해보기

- [ ] `conda activate py311` → `pip install ultralytics`
- [ ] `train.py` 작성 (모르는 부분은 코치·공식문서 참고)
- [ ] dataset 폴더와 같은 위치에서 `python train.py`
- [ ] 첫 실행은 `epochs=2`, `batch=1` 로 돌아가는지만 확인
- [ ] 돌아가면 epochs·batch 를 바꿔 다시 학습
