# 00. 큰 그림

## 전이학습 · Fine-tuning

미리 학습된 `yolo11n-cls.pt` 를 출발점으로 새 클래스를 추가 학습한다. 전이학습의 한 기법이 **Fine-tuning**.

```
pretrained 가중치  →  새 데이터로 미세 조정  →  분류 헤드 자동 교체
train 학습         →  val 검증              →  test 최종 확인
```

## 세 폴더의 역할

| 폴더 | 역할 | 비율 | 가중치 변경 |
|---|---|---|---|
| train | 모델이 직접 보고 배움 | 70~80% | O |
| val | 매 epoch 끝 성능 측정, best.pt 선정 기준 | 10~15% | X |
| test | 학습 후 처음 보는 이미지로 최종 평가 | 10~15% | X |

## 알아둘 말

| 용어 | 뜻 |
|---|---|
| 전이학습 | 이미 학습된 모델의 지식을 새 문제에 이어 쓰기 |
| Fine-tuning | pretrained 가중치를 출발점으로 전체를 미세 조정 |
| 분류 헤드 | 맨 마지막 층. 출력 칸 수 = 클래스 수 |
| 과적합 | train 은 잘 맞히는데 새 이미지는 못 맞힘 |
