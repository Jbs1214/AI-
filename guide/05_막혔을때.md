# 05. 막혔을 때

증상 → 먼저 스스로 확인할 것. 원인을 찾으면 직접 고친다.

| 증상 | 확인할 질문 |
|---|---|
| `ModuleNotFoundError: ultralytics` | `conda activate py311` 했나? 같은 환경에서 `pip install` 했나? |
| 클래스를 못 찾음 / 0 classes | `data` 가 `dataset` 폴더를 가리키나? 클래스 폴더 안에 이미지가 있나? |
| val 관련 오류 | `val` 폴더 철자, train 과 같은 클래스 폴더명인가? |
| 메모리 부족 | `batch` 를 줄이면? `imgsz` 는? |
| 정확도가 너무 높음(100%) | train 과 val 에 같은 이미지가 있지 않나? |
| 한 클래스만 예측 | 클래스별 수량이 같은가? |
| 모델 다운로드 실패 | 네트워크·방화벽 확인 후 강사에게 문의 |

## 도움 요청 순서

1. 오류 **전문**을 복사
2. `dataset` 폴더 트리 확인
3. 코치(`yolo-cls-coach`)에게 둘 다 보여주기
4. 같은 오류 2회 반복 시 강사에게 화면 공유
